# Информационные системы, лабораторная работа 1

Вариант: 12030, Organization.
Стек: Jakarta EE, CDI, EclipseLink, PostgreSQL, Java 17.

## Текущие изменения

Добавлена JWT-аутентификация и роли USER/ADMIN. Пользователь видит свои данные,
администратор все данные; изменять и удалять можно только свои объекты.
Вложенные объекты и SQL-функции учитывают владельца. Регистрация создаёт USER,
назначение ADMIN выполняется в БД. Незавершённое отображение загрузок из файла
не входит в изменение системы пользователей.

## Устаревшие артефакты

- report/report.tex, report/report.pdf и report/uml: не отражают пользователей, JWT и owner_id.
- docs/code-guide.md и docs/repository-guide.md: не отражают аутентификацию и фильтрацию по владельцу.

Отчёт и гайды не обновлялись, поскольку пользователь запросил реализацию и коммит кода.
